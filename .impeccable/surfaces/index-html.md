# Surface: Λέξεις app (index.html, all screens)

Mode: operate. Audience: Russian speakers learning everyday Modern Greek on iPhone (home-screen PWA), short daily sessions and on-the-go word adding.
Task: add a word in one field; review due cards across three directions; browse/edit the dictionary; manage reminders, keys, export/import, account.
Constraints: keep every behaviour; Russian UI, Greek content; light/dark by system; name Λέξεις.
User-pinned (2026-10-11): metro-line idea; header as its own centred block; all bottom links grouped in one list block, rarely used ones under «Ещё»; account row with Google avatar; four selectable colour themes (Графит, Эгейский, Оливковый, Ночное метро) with a theme setting.

## Direction contract

THESIS: Each word rides three metro lines (blue Ε Узнать, red Р Написать, green ♪ Услышать) through stations 1·3·7·14·30·60 days; refuses the generic single "review N" card and the grey list with one blue accent.
OWN-WORLD: Rounded white blocks on a tinted ground, Commissioner (Greek type designer) throughout, three type sizes ranked by weight and reversal; Athens line colours M1/M2/M3 reserved for the three directions; one primary reversed button per screen; themes swap ground/primary only, never the line colours.
STORY: Opening shows today's load per line at a glance; one tap "Поехали" starts review; verdicts stamp onto the card and stay; the card view shows each line's position among its stations.
FIRST VIEWPORT: Centred header block (Λέξεις, avatar button in its top-right corner, word count, streak pill); "ΣΗΜΕΡΑ · сегодня" block with 72px count, three line rows (badge, station track with dots at this direction's progress, count), full-width "Поехали"; add-word block; grouped menu list (Словарь, Как это работает). Everything personal (statistics, reminders, theme, keys, export/import, sign-out) is on the account screen behind the avatar in the header corner.
